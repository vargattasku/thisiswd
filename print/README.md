# 청첩장 엽서 (A6 세로 · 양면)

모바일 청첩장(`index.html`)의 톤앤무드를 그대로 옮긴 실물 인쇄용 원본입니다.

## 규격

| 항목 | 값 |
|---|---|
| 재단 사이즈 | 100 × 148 mm (A6) |
| 도련 포함 | **106 × 154 mm** (사방 3mm) |
| 해상도 | 300 DPI |
| 픽셀 | **1252 × 1819 px** |
| 색상 | RGB (⚠ 아래 CMYK 항목 참고) |
| 면 구성 | 양면 |

- **재단선** — 가장자리에서 3mm 안쪽. 실제로 잘리는 위치입니다.
- **안전선** — 재단선에서 5mm 더 안쪽. 글자는 모두 이 안에 있습니다.
- 배경은 도련 끝까지 채워져 있어 재단이 조금 밀려도 흰 테두리가 생기지 않습니다.

## 파일

| 파일 | 용도 |
|---|---|
| `postcard-front.html` / `postcard-back.html` | **원본.** 내용 수정은 여기서 합니다 |
| `postcard-front.jpg` / `postcard-back.jpg` | 인쇄소 제출용 (300DPI) |
| `postcard-front.psd` / `postcard-back.psd` | 레이어 분리본 (포토샵 편집용) |
| `build.js` / `package.json` | 위 JPG·PSD 생성 스크립트 |

### PSD 레이어 구성

아래에서 위로 쌓여 있습니다.

- **앞면** — 배경 / 코너 리본 / 사진 / 글자 / *가이드(숨김)*
- **뒷면** — 배경 / 코너 리본 / 글자 / *가이드(숨김)*

`가이드` 레이어는 재단선(빨강)·안전선(파랑) 표시용이며 **숨김 상태**입니다. 인쇄 전에 삭제하세요.

> 글자는 이미지로 래스터화되어 있습니다(텍스트 레이어 아님). 문구를 고칠 때는 포토샵이 아니라 HTML을 고치고 다시 빌드하는 편이 깔끔합니다.

## 다시 만들기

HTML을 수정한 뒤:

```bash
cd print
npm install      # 처음 한 번만
node build.js
```

Chrome이 설치되어 있어야 합니다. 스크립트가 자동으로 찾지 못하면 `build.js`의 `findChrome()` 안 경로 목록에 추가하세요.

## ⚠ 인쇄 전 반드시 확인할 것

### 1. 임시 데이터가 그대로 들어가 있습니다

모바일 청첩장에서 아직 채워지지 않은 값을 그대로 옮겨왔습니다. **인쇄하면 되돌릴 수 없으니** `postcard-back.html`의 `TODO` 주석 부분을 실제 정보로 바꾸고 다시 빌드하세요.

- 신랑측 아버지 `김○○`, 어머니 `이○○`
- 계좌번호 `국민 123456-78-901234`, `농협 302-0000-0000-00`

신부측 정보와 신랑 연락처는 실제 값으로 보이지만, 한 번 더 확인해 주세요.

### 2. CMYK 변환이 필요합니다

이 파일은 **RGB**입니다. 인쇄는 CMYK라 변환이 필요한데, 이 청첩장의 파란색 `#2030d0`은 **RGB에서만 낼 수 있는 선명한 색이라 CMYK로 바꾸면 반드시 탁하고 어두워집니다.** 화면에서 보던 그 파랑이 그대로 나오지 않습니다.

선택지는 셋입니다.

1. 인쇄소에 RGB 파일을 주고 변환을 맡긴다 (가장 흔하지만 결과는 복불복)
2. 포토샵에서 직접 CMYK로 변환하고, 탁해진 파랑을 눈으로 보정한다
3. 인쇄소에 **별색(Pantone) 지정**을 문의한다 — 비용은 오르지만 선명한 파랑이 나옵니다

**교정쇄(샘플 인쇄)를 꼭 받아보시길 권합니다.** 소량이라도 실물 색을 확인한 뒤 본 인쇄를 넘기는 게 안전합니다.

### 3. 폰트 라이선스

`Brittany Signature`, `Festigan`은 무료 배포본일 경우 **상업적 사용이나 인쇄물 제작이 제한**될 수 있습니다. 청첩장은 판매물이 아니라 대개 문제되지 않지만, 배포처의 라이선스를 한 번 확인해 두시면 좋습니다. (파일에는 이미지로 렌더링되어 들어가므로 폰트 파일 자체가 인쇄소로 넘어가지는 않습니다.)

### 4. 사진 해상도

앞면 사진은 원본 `image/wd.jpg`(4672×7008)를 사용합니다. 웹용 `wd-web.jpg`(900×1350)는 300DPI 인쇄에 해상도가 모자라니 바꾸지 마세요.
